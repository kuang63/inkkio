# Inkkio 

## Description

Inkkio empowers users to "ink" and send a virtual card to their loved ones for special occasions! The platforms provides a multitude of editing options, including text, drawings, images, stickers, and background textures, for users to customize their cards. If you don't know where to start, Inkkio also offers templates for you to choose from.
